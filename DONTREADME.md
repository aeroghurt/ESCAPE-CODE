## LEVEL 1 WALKTHROUGH
1. Type the command `1`. It will give you the cryptic text WYRHOSYUIDPSOET. Using some trial and error, you will find that it's a 5x3 scytale cipher. You could put it into https://www.dcode.fr/scytale-cipher (preferred), or do it by hand (why would you do this) (but I'd understand if you were d3rlord3). Type `answer`. Once prompted, write `WHYDOYOUPERSIST`. All the other commands are uh... irrelevant, unless you're the typa person to get into the lore then yippee!!! <br>

## LEVEL 2 WALKTHROUGH
2. The level shows a braille-like message (not really). You'd be partially right, it does involve braille. This challenge is a bit tedious, since you'd have to convert all the numbers given to braille, and then input that into a Conway's Game of Life simulation, and then press Next to get the first generation (totally didn't steal that idea from Wifies). Whatever matches the message given is the answer, which is B (6698). Type `answer` and then type `B`. Does the number have any significance to the lore? Uhhhh no. <br>

## LEVEL 4 WALKTHROUGH
4. Type `3` to walk around, then type `n` for north, since 1200 in military time (+ air force, etc.) is north. Or it's just common knowledge. You see a clock pointing at 0730 which is directly southwest, so press `1` to walk around, and write `sw`. The next clock seems to be cuckoo, but it really just speaks in another tongue (morse code). Tick is . and ticktick is -, pauses are just to separate the letters. It translates to `FINALE`. Press `1` to answer there you have it! The end =)
